Drop your files here:

- **Résumé PDF** — e.g. `resume.pdf`. Then set `resume: assets/resume.pdf`
  in `content/about.yaml`.
- **Headshot** — e.g. `photo.jpg`. Then set `photo: assets/photo.jpg` in
  `content/about.yaml`.

Both are optional — leave the fields in `about.yaml` blank and the site
keeps its current placeholders (a disabled Download PDF button, a "photo
here" box).
